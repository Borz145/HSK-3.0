# HSK 3.0 · тренажёр

Тренажёр по новой программе HSK 3.0 (2025): уровни 1–3, 1000 слов с переводом на русский, пиньинем и примерами, озвучка слов, карточки, тест, билеты, пробники, иероглифы, диалоги и реплики с разбором.

Сайт статический: достаточно залить все файлы этой папки на любой хостинг (GitHub Pages, Netlify, Cloudflare Pages). Прогресс хранится в браузере каждого пользователя.

## Источники и лицензии
- Списки слов: HSK 3.0, программа 2025 года (сверено по mandarinbean.com и studycli.org).
- Озвучка: проект [audio-cmn](https://github.com/hugolpz/audio-cmn), дикторы Yue Tan и Chen Wang, лицензия [CC BY-SA](https://creativecommons.org/licenses/by-sa/4.0/). Записи обрезаны, нормализованы по громкости, часть слов собрана из записей слогов. Аудио в файлах a1.js, a2.js, a3.js распространяется на тех же условиях CC BY-SA.
